Harbor 01 · The Intake Gate

ประตูดักคลื่น: ไดโอดและการเรียงกระแสครึ่งคลื่น

คลื่นไฟฟ้าสลับที่เข้ามาที่ท่าเรือมีทั้งซีกบวกและซีกลบสลับกันไปมา แต่อุปกรณ์ในเมืองต้องการกระแสตรงทางเดียว หน้าที่ของ ไดโอด คือประตูทางเดียว ยอมให้คลื่นผ่านเฉพาะทิศเดียว นี่คือหลักการของ วงจรเรียงกระแส (Rectifier) ทั้งหมด

สภาวะต่อขั้วอย่างไรไดโอดทำอะไรแรงดันตกคร่อมไดโอด
ไบอัสตรง (Forward bias)ขั้วบวกเข้าที่แอโนด (P) ขั้วลบเข้าที่แคโทด (N) นำกระแส เสมือนสวิตช์ปิดคงที่ประมาณ 0.7 V (ซิลิคอน) หรือ 0.3 V (เจอร์เมเนียม)
ไบอัสย้อนกลับ (Reverse bias)ขั้วบวกเข้าที่แคโทด (N) ขั้วลบเข้าที่แอโนด (P) ไม่นำกระแส เสมือนสวิตช์เปิดรับแรงดันย้อนกลับไว้เต็มจำนวน จนถึงค่า PIV
สิ่งที่ต้องจำให้แม่นค่าเหตุผล
แถบขาว (หรือแถบสีอ่อน) บนตัวถังคือด้าน แคโทดกระแสสมมติไหลจากแอโนดไปแคโทด คือไหล เข้าหาแถบ แล้วออกไป
แรงดันยอดจากหม้อแปลงVm = Vrms x √2หม้อแปลงระบุค่าเป็น Vrms เสมอ ต้องแปลงเป็นค่ายอดก่อนใช้ทุกครั้ง
แรงดันเฉลี่ยครึ่งคลื่นVdc = Vp/π ≈ 0.318 Vpมีคลื่นเพียงครึ่งเดียวใน 1 คาบ ค่าเฉลี่ยจึงต่ำ
ความถี่ริปเปิลของครึ่งคลื่นf_r = f_inได้ลูกคลื่นเอาต์พุต 1 ลูกต่อคาบอินพุต 1 คาบ
PIV ของครึ่งคลื่นPIV = Vmตอนไบอัสย้อนกลับ แรงดันยอดทั้งก้อนตกคร่อมไดโอดตัวเดียว
สูตรที่ใช้ในท่านี้
แรงดันยอดของขดทุติยภูมิ: Vm = Vrms x √2 · แรงดันยอดที่ออกไปถึงโหลด: Vp = Vm − VF (VF คือแรงดันตกคร่อมไดโอด)
แรงดันเฉลี่ย (ค่าที่มิเตอร์ DC อ่านได้): Vdc = Vp / π · ค่าประสิทธิผลของครึ่งคลื่น: Vrms(out) = Vp / 2
กระแสเฉลี่ยที่ไหลผ่านโหลด: Idc = Vdc / RL · ความถี่ริปเปิล: f_r = f_in · แรงดันย้อนกลับสูงสุด: PIV = Vm

ตัวต้านทานอนุกรมของวงจรซีเนอร์: Rs = (Vin − Vz) / (Iz + IL) · กระแสที่ไหลผ่านซีเนอร์จริง: Iz = (Vin − Vz)/Rs − IL
กำลังสูญเสียในซีเนอร์: Pz = Vz x Iz · ต้องคุมให้ Iz อยู่ระหว่าง Izk (ค่าต่ำสุดที่ยังตรึงได้) กับ Izm (ค่าสูงสุดตามพิกัดกำลัง)
ข้อควรระวังของหน่วย: C หน่วยฟารัด — 470 µF ต้องแทนเป็น 470 x 10⁻⁶ F มิฉะนั้นคำตอบจะผิดไปหนึ่งล้านเท่า
