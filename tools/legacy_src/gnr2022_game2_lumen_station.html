Station 01 · The Trim Bay

แท่นปรับเทียบ: ตัวต้านทานปรับค่าได้

ตัวต้านทานปรับค่าได้ (Variable Resistor, VR) มี 3 ขา เสมอ แต่จะทำหน้าที่อะไรขึ้นอยู่กับว่าเราต่อกี่ขา นี่คือจุดที่นักศึกษาสับสนมากที่สุดในบทนี้ ต่อครบ 3 ขา = แบ่งแรงดัน ต่อเพียง 2 ขา = ปรับความต้านทานอนุกรม

รูปแบบการต่อจำนวนขาที่ใช้ทำหน้าที่ผลลัพธ์ที่ได้
โพเทนชิโอมิเตอร์ (Potentiometer)3 ขาตัวแบ่งแรงดัน ได้ Vout ระหว่าง 0 ถึง Vin ตามตำแหน่งขากลาง โดยกระแสในตัวต้านทานคงที่
รีโอสแตต (Rheostat)2 ขาตัวต้านทานอนุกรมปรับค่าได้ ควบคุมกระแสที่ไหลในวงจร ค่าความต้านทานเปลี่ยนตามตำแหน่งขากลาง
ชนิดลักษณะเด่นใช้ที่ไหน
VR แบบหมุน (Rotary) เทเปอร์ Bความต้านทานเปลี่ยน เป็นสัดส่วนตรง กับมุมหมุน (Linear)ปรับแรงดันอ้างอิง ตั้งจุดทำงาน
VR แบบหมุน เทเปอร์ Aเปลี่ยน ช้าในช่วงต้น เร็วในช่วงท้าย (Logarithmic)ควบคุมความดังเสียง ให้ตรงกับการรับรู้ของหูมนุษย์
ทริมเมอร์ / พรีเซต (Trimmer / Preset)ตัวเล็ก บัดกรีบนแผ่นวงจร ปรับด้วยไขควงปรับเทียบ (calibrate) ครั้งเดียวตอนผลิต ไม่ให้ผู้ใช้ปรับ
VR แบบ Multi-turn (เช่น 10 รอบ)กระจายช่วงค่าทั้งหมดไปตลอด 10 รอบ จึงตั้งค่าได้ละเอียดกว่า 10 เท่างานปรับเทียบเครื่องมือวัดที่ต้องการความละเอียดสูง
สูตรที่ใช้ในสถานีนี้
โพเทนชิโอมิเตอร์: Vout = Vin x R_ล่าง / R_รวม · กระแสในตัวต้านทาน I = Vin / R_รวม
รีโอสแตต: I = Vin / (R_ตั้งค่า + R_โหลด) · กำลังที่ตกบน VR P = I² x R_ตั้งค่า
เทเปอร์ B (Linear): R_ล่าง / R_รวม = α · เทเปอร์ A (Log แบบจำลองมาตรฐาน): R_ล่าง / R_รวม = (10^(2α) − 1) / 99
เมื่อ α คือสัดส่วนมุมหมุนจากปลายล่าง มีค่า 0 ถึง 1 · แรงดันสูงสุดที่คร่อม VR ได้โดยไม่เกินพิกัด Vmax = √(P_พิกัด x R)

ห้องทดลองที่ 1: แท่นปรับเทียบ VR (หมุนแกนได้จริง)

ลากหมุนแกนด้วยเมาส์หรือนิ้ว หรือเลื่อนสไลเดอร์ก็ได้ แล้วดูมิเตอร์ตอบสนองทันที ทดลองให้ครบทั้ง 4 อย่าง (โหมด POT, โหมดรีโอสแตต, เทเปอร์ B, เทเปอร์ A) เพื่อรับ XP เต็ม

Station 02 · The Photocell Deck

ดาดฟ้าเซลล์แสง: LDR และการต่อในวงจรแบ่งแรงดัน

LDR (Light Dependent Resistor) หรือโฟโตรีซิสเตอร์ ทำจากสารกึ่งตัวนำ เช่น แคดเมียมซัลไฟด์ (CdS) เมื่อโฟตอนตกกระทบ พลังงานแสงจะปลดปล่อยพาหะอิสระเพิ่มขึ้น ทำให้ นำไฟฟ้าได้ดีขึ้นและความต้านทานลดลง นี่คือเหตุผลเชิงฟิสิกส์ที่ว่า ยิ่งสว่างยิ่งความต้านทานต่ำ ซึ่งเป็นข้อที่นักศึกษาตอบกลับด้านบ่อยที่สุด

สภาพแสงความสว่างโดยประมาณความต้านทาน LDR (รุ่นอ้างอิงในเกมนี้)
มืดสนิท / ปิดฝาครอบต่ำกว่า 1 lxสูงมาก ระดับหลายร้อย kΩ ถึง MΩ
ห้องมืดสลัวประมาณ 10 lxประมาณ 10 kΩ (ค่าอ้างอิง R10)
ห้องเรียนเปิดไฟประมาณ 300 lxประมาณ 0.87 kΩ
กลางแจ้งมีเมฆประมาณ 10,000 lxประมาณ 79 Ω
แบบจำลองที่ใช้ในเกมนี้ (ตรงกับสเปกของ LDR ชนิด CdS ทั่วไป)
R_LDR = R10 x (E / 10)^(−γ) โดย R10 = 10 kΩ ที่ 10 lx และ γ = 0.70
เมื่อใส่ลอการิทึมทั้งสองข้าง: log R = log R10 − γ (log E − 1) จึงได้ เส้นตรงบนกราฟ log-log ที่มีความชันเท่ากับ −γ — ค่า γ หาได้จากสองจุดใด ๆ ด้วย γ = log(R1/R2) / log(E2/E1)
วงจรแบ่งแรงดัน: Vout = Vcc x R_ล่าง / (R_บน + R_ล่าง) — "R_ล่าง" คือตัวที่คร่อมระหว่างจุดวัดกับกราวด์

ห้องทดลองที่ 2: ดาดฟ้าเซลล์แสง (เลื่อนความสว่างแล้วดูค่าจริง)

เลื่อนสไลเดอร์ความสว่าง สลับตำแหน่งของ LDR แล้วสังเกตว่า Vout เปลี่ยนทิศตรงกันข้ามอย่างไร ทดลองให้ครบทั้ง 4 อย่าง (มืดสุด สว่างสุด LDR อยู่บน LDR อยู่ล่าง) เพื่อรับ XP เต็ม

คำนวณ Vout ได้แม่น เข้าใจว่าทำไมค่าที่วัดได้ตกลงเมื่อมีโหลดจริงมาต่อ (loading effect) และแปลงแรงดันเป็นรหัส ADC 10 บิตได้ถูกต้อง

Station 03 · The Uplink Room

ห้องส่งค่าเข้า ADC: ตัวแบ่งแรงดัน โหลด และการแปลงเป็นตัวเลข

วงจรแบ่งแรงดันคือวงจรที่พบบ่อยที่สุดในงานเซนเซอร์ แต่มีกับดักสำคัญคือ สูตร Vout = Vin x R2/(R1+R2) ใช้ได้เฉพาะตอนที่ยังไม่มีโหลดมาต่อ เมื่อมีโหลดจริงมาคร่อม R2 ค่าความต้านทานที่จุดนั้นจะกลายเป็น R2 ขนานกับ RL ทำให้แรงดันตกลง

สูตรที่ใช้ในสถานีนี้
ไม่มีโหลด: Vout = Vin x R2 / (R1 + R2) · เลือกค่า R1 เมื่อทราบ Vout ที่ต้องการ: R1 = R2 (Vin − Vout) / Vout
มีโหลด RL คร่อม R2: R2' = (R2 x RL) / (R2 + RL) แล้วจึงใช้ Vout' = Vin x R2' / (R1 + R2')
ความคลาดเคลื่อนจากโหลด: %error = (Vout − Vout') / Vout x 100
ADC ความละเอียด n บิต: code = ปัดจำนวนเต็มของ [ Vin_adc / Vref x (2ⁿ − 1) ] · ADC 10 บิตมีค่ารหัส 0 ถึง 1023 · LSB = Vref / (2ⁿ − 1)
กฎนิ้วโป้งของวิศวกร: ให้อิมพีแดนซ์อินพุตของภาคถัดไป สูงกว่าค่า R ของตัวแบ่งอย่างน้อย 10 เท่า จึงจะถือว่า loading effect น้อยพอที่จะละเลยได้
