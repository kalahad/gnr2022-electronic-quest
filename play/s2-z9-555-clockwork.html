Room 02 · Monostable

ห้อง 2: Monostable ตั้งเวลาครั้งเดียว

t = 1.1 × R × C (R เป็น Ω, C เป็น F, t เป็นวินาที) ตัวอย่าง: R = 100 kΩ, C = 10 µF → t = 1.1 × 100 000 × 0.000 01 = 1.1 s ออกแบบ: ต้องการ 11 s มี R = 500 kΩ → C = 11 / (1.1 × 500 000) = 20 µF
ลำดับเกิดอะไรขึ้น
1 รอOUT = LOW ขา 7 คายประจุ C ค้างไว้ที่ 0 V
2 กดปุ่มขา 2 ถูกดึงต่ำกว่า 1/3 VCC → OUT = HIGH ขา 7 ปล่อย C ให้ชาร์จผ่าน R
3 จบเวลาแรงดัน C ถึง 2/3 VCC (ที่ t = 1.1RC) → OUT = LOW ขา 7 คายประจุ C ทันที
จำให้ขึ้นใจ: t = 1.1RC · กด 1 ครั้งได้ 1 พัลส์ (one-shot) · R หรือ C เพิ่ม 2 เท่า เวลาเพิ่ม 2 เท่า

ห้องทดลอง: นาฬิกาจับเวลา

ตั้ง R และ C ให้ได้เวลาตามภารกิจ (คลาดได้ไม่เกิน 5%) แล้วกดปุ่ม TRIG ดูไฟติดและแรงดัน C ขึ้นจนถึง 2/3 VCC

Room 03 · Astable

ห้อง 3: Astable สร้างจังหวะต่อเนื่อง

f = 1.44 / ((RA + 2RB) × C) BPM = f × 60 tH = 0.693 (RA + RB) C (ชาร์จผ่าน RA และ RB) tL = 0.693 RB C (คายผ่าน RB อย่างเดียว) duty = (RA + RB) / (RA + 2RB) × 100% → วงจรพื้นฐานได้มากกว่า 50% เสมอ ตัวอย่าง: RA 1 kΩ, RB 10 kΩ, C 10 µF → f = 1.44 / (21 kΩ × 10 µF) ≈ 6.9 Hz, duty ≈ 52%
จำให้ขึ้นใจ: C หรือ R มากขึ้น = ช้าลง · ต้องการ duty ใกล้ 50% ให้ RA ≪ RB · ขับรีเลย์หรือโหลดหนักผ่านทรานซิสเตอร์ (โซน 7)

ห้องทดลอง: ไฟกะพริบตามจังหวะเพลง

เลือก RA, C แล้วปรับ RB ให้ไฟกะพริบตรง BPM เป้าหมาย (คลาดได้ไม่เกิน 3%) ทำให้ครบ 3 เพลง
